# Expense Tracker - Product Requirements Document

## App Overview
A premium expense tracker web app for personal finance management

## Pages
- **Dashboard page** (main page) - shows summary cards, recent expenses, charts
- **Expenses page** - full list of all expenses with filters
- **Add/Edit expense page** - form to add or edit an expense

## Features
- Add expense with: title, amount, category, date, notes
- Categories: Food, Transport, Shopping, Bills, Entertainment, Other
- Dashboard summary cards: Total Spent, This Month, Top Category, Total Expenses
- Bar chart showing spending by category
- Line chart showing spending over time
- Filter expenses by category and date range
- Delete expense
- Edit expense
- All data saved in localStorage

## UI/UX
- Premium dark theme using Mira shadcn preset
- Smooth animations
- Fully mobile responsive
- Clean sidebar navigation
